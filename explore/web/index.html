 WELCOME TO EXPLOREOS

从好问题，到有依据的下一步。

  1. 保存你的问题

    说清楚想弄明白什么。无需写出完整计划，也不需要先指定智能体分工。

  2. 提供可检查的材料

    添加访谈、笔记或原文片段。没有材料时，系统只做推理，成果会保留这个限制。

  3. 明确开始一轮探索

    选择演示或真实探索。演示使用预设情景；真实探索需要服务端模型配置和共享预算。

  4. 检查成果，再继续

    看发现、原文与未决质疑。添加反例、修改关注点或追加有限轮次，旧记录继续保留。

如何启用真实探索？

在安装主机的私有 .env 中设置 DEEPSEEK_API_KEY，再运行 docker compose up -d。源码安装参照 CLOUD.md。模型密钥不填入浏览器，登录仍使用 ClawInstitute 的实例令牌。

创建对话框显示本机配置与共享预算；配置存在不表示供应商连接已经验证。开始真实探索才会调用模型。预算跨课题共享，不因重启或追加轮次重置。

快捷键：Ctrl / ⌘ + K 查找课题 · 在视图标签上用方向键切换。外观设置保存在此浏览器。
