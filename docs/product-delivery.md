# ExploreOS 产品交付

目标是个人或单一可信使用者的 Linux 产品：沿用 ClawInstitute 的登录、讨论与文件，打开探索入口即可提出问题、查看成果，之后回来继续。路线图中的工程工作服务于这条使用过程。

## 日常使用

1. 打开 ExploreOS，沿用原 ClawInstitute 登录。
2. 新建探索，只需填写问题。默认三个参与者，项目代号自动生成；参与者与对照配置在高级设置中。
3. 选择真实探索或明确标记的零付费演示。真实执行设置与课题一起保存，共享预算在不同课题、轮次与重试之间保留。
4. 按需添加材料，然后推进一轮。创建、保存设置、添加材料及查看简报均不调用模型。
5. 默认查看阶段成果：当前发现、署名复查回应、未决问题与质疑、下一步操作。每条发现可回到其原始依据。
6. 补材料、修改关注点或暂停，之后重新打开继续。旧问题的发现保留原版本；已撤回及修订的旧主张进入历史，过期回应不会当作生效变化。
7. 下载可离线阅读的 Markdown 简报，或导出完整原始记录。简报整理已有内容，不额外生成模型总结。

原生入口、材料限制和高级操作见 [探索工作台](workbench.md)。

## 完成标准与实际缺口

| 交付要求 | 验收方式 | 当前边界 |
| --- | --- | --- |
| 提问到成果的完整操作 | 真实浏览器完成创建、材料、多轮、改向、导出及重新打开 | 机械场景可验证流程，不能替代真实内容质量 |
| 可检查的成果 | 主张、原文、问题版本、回应和异议对应；历史不冒充当前发现 | 简报是署名记录的投影，不能自动验证事实 |
| 真实多智能体可用 | 在实际模型上完成开放任务与跨轮接续，抽查材料支持与行动变化 | 当前云环境未放行 api.deepseek.com，新一轮真实验收尚未运行 |
| 日常接续与恢复 | 重开页面、服务重启、未知结果不重发、预算不重置 | 有界唤醒仍需明确运行机器；开发环境不是常驻部署 |
| 可安装与持久运行 | 非 root 容器启动、优雅停止、新容器读取原卷；冷备恢复另有真实检查 | 已有 [安装包与部署步骤](deployment.md)，目标长期主机与异地备份位置尚未落实 |
| 如实交付 | 可访问入口、使用说明、真实案例及限制，与 main 代码一致 | 不用合并、测试数量或模拟案例代替产品完成 |

先完成上述闭环，再按真实使用与评测证据扩展更多工具和模型组合。已有冻结评测、历史真实个案及质量验收要求继续保留，见 [实施路线](roadmap.md)。
