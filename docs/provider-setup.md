# 在页面中配置 DeepSeek

使用实例登录令牌进入 ExploreOS，点击页面右上角「模型设置」。这里的 DeepSeek API 密钥与 ClawInstitute 登录令牌用途不同。

## 保存与开始

1. 在专用的密码输入框填写 DeepSeek API 密钥，点击「保存模型配置」。
2. 页面确认本机配置已保存。保存不会发起模型请求，也不创建或增加预算。
3. 返回课题，确认真实探索方式与共享预算，再明确点击「推进一轮」。

配置存放在安装主机的 `.runtime/service/private/provider.json`，文件为 600、目录为 700 权限。浏览器不会回显已有密钥，也不将它写入 localStorage、课题材料、报告或数据库。密码输入框在保存、关闭和重新打开时清空。

仅持有实例登录令牌的访问者可以修改；这是现有单一可信使用者的认证范围，不是新增的多租户角色系统。不要把实例令牌或模型密钥放进问题、材料、公开 issue 或截图。

## 环境变量与已有配置

`DEEPSEEK_API_KEY` 环境变量仍优先，存在时本页只读，需要在原环境配置中修改。原 `.runtime/secrets/deepseek-api-key` 私有文件继续兼容；页面保存的配置优先于该原文件，但不改写它。

「移除本机保存的密钥」只移除本页创建的配置。若环境变量或原私有文件仍提供凭据，页面会显示其来源，不宣称所有凭据都已清除。

每次保存绑定已读取的配置版本；另一个页面已修改时拒绝过期写入，需要刷新核对后再保存。

## 持久化、预算与恢复

容器使用既有 service 命名卷保留本机配置，正常重建不会丢失。冷备归档排除模型密钥，恢复到新实例后应重新配置；实例登录令牌和研究数据仍按原备份规则处理。

更换密钥不重置共享预算、请求数量或未知消耗。已启动的轮次继续使用开始时读取的配置，后续执行才读取新配置。

「已保存」表示私有配置写入成功；供应商权限、余额、网络和真实输出质量要在实际运行时验证。当前不提供保存时自动模型探针。
