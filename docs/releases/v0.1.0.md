# ExploreOS v0.1.0

状态：待验收，禁止正式发布

ExploreOS 在原 ClawInstitute 内提供开放问题的多智能体探索。填写问题、添加材料，在阶段成果中阅读发现、来源、分歧和未决问题，修改关注点后继续。

## 已交付的产品能力

- 原生登录、讨论及共享文件；自动项目代号、默认三名参与者、保存执行设置。
- 发现、认识变化和材料依据；当前关注点与历史/修订/撤回记录分开，保留异议。
- 暂停、改向、有限追加轮次、失败核对与显式重试，原始记录和预算保留。
- 可离线阅读的阶段简报、完整导出、带适用条件的跨课题引用。
- 非 root Linux amd64 安装包、持久卷、优雅停止、冷备及空卷恢复。

## 已验证与尚未完成

108 项工程测试、真实浏览器流程、容器更换、约 2.28 GB 数据恢复、安装包重新加载和主机 HTTP 访问已有通过记录。具体 CI 随拟发布提交重新核对，不以其他提交的绿灯代替。

当前真实模型密钥已在私人配置中提供，执行依赖已就绪；云环境仍未放行 api.deepseek.com。本轮真实质量抽查、冻结重复评测及长期目标主机/异地备份尚未完成，不能把模拟结果或 CI 成功视为这些项目已经验收。

## 发布前必须完成

1. 完成当前执行指纹下的真实探索质量抽查，留存主张支持范围、反例、分歧和接续依据。
2. 完成冻结的重复对照评测与署名评阅，如实报告无收益、更差案例及代价。
3. 在实际长期运行主机完成访问、持久接续和异地备份恢复核对。
4. 在 `.release/acceptance.json` 记录以上真实证据及接受状态，核对当前执行指纹，并将本说明状态改为“发布就绪”。
5. 合入 main 后，等待同一提交两套 CI 及安装包验证全部完成，再创建版本标签。发布流程复用该提交的已验证安装包，校验源码提交与内部校验文件后上传永久 release 附件。

目前本文件是可评阅的发布草稿，不是已发布的版本公告。
