# ADR 0007：插件前台叶子的运行所有权

日期：2026-10-25。状态：已实现；真实单叶子兼容和机械验收已通过，长期效果未验收。

ADR 0006 完成了 Pi 库接入和插件核对。后续用户要求继续推进，本次增加可选 `pi-subagents` 后端，复用固定插件的公开结构化委派接口，逐步替代自行实现通用子会话执行的需要。

首个配置只允许一个 fresh、零工具、单供应商请求的前台叶子；父宿主不调用模型，不打开后台计划或嵌套委派。插件拥有子会话/runId/终态；ExploreOS 只记录稳定委派身份与事件回执引用，继续拥有探索协议和共享费用准入。共享内容仍由 ClawInstitute 保存。

恢复必须验证插件终态，不能用供应商已返回文本代替运行完成。回执缺失/损坏/身份不符不授权再次派发；取消保留供应商未知预留。既有 Pi、CC 和模拟项目继续使用原后端，新增路径不追溯改变历史案例。

所有权、实际接口、测试、费用和已知边界见 [前台委派接入](../subagent-integration.md)。后台、复杂工具和工作台的复用需要后续独立验收，不据此次单叶子兼容宣布 M2 或整个产品完成。
