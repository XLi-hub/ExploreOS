# ADR 0009：评测、工作台与有界持续运行

状态：工程实现，真实质量与长期运行验收另行记录。

## 依据

M2 需要冻结输入、重复对照和人工评阅；M3 需要开放探索的认识视图；M4/M5 需要带出处的记忆和可靠接续。现有 ClawInstitute 发布包已经有通用讨论、文件和数据库，开放任务补丁已经支持 1–8 个参与者，Project 已经有调用认领、预算和恢复。扩展不应建立竞争的状态权威。

## 决定

- 评测设计、案例对应和署名评阅保存在同一 ClawInstitute 文件系统。案例使用原 Project；campaign 不拥有模型执行状态。冻结包默认八个任务、四种配置和三项明确限定的语义消融。
- 工作台是本地浏览器投影与控制适配。它只补问题、方向、来源支持和认识变化视图；继续使用既有帖子和文件服务，未重建讨论平台。token 留在服务端。
- 人数参数传给现有开放任务物化器，参与者上下文仍独立；暂不在没有评测证据时开放任意工具或供应商混合执行。
- 跨课题记忆只由用户明确关联，保留出处和条件；每次取回检查源课题状态，不能自动晋升为通用事实。
- 定时配置默认禁用、有限轮数、本地通知。唤醒拥有到期事件，Project 拥有执行；两者以目标轮次和稳定身份关联。重复触发、停用、未知结果与重启不能创建重复调用。

## 边界

匿名评阅只隐藏显式标签，文本可能透露配置；一次机械运行不构成协作收益。执行失败笔记消融不代表所有领域失败经验的消融。真实模型预算、凭据、人工质量评阅、长期机器/存储和实际运行频率都必须明确，不能由实现文件代替验收。详见 [评测](../evaluation-pilot.md)、[工作台](../workbench.md) 和 [持续运行](../daily-use.md)。
