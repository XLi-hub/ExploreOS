# ADR 0010：有界执行索引与不可变调用归档

## 观察到的阻塞

固定 ClawInstitute 发布包在 `src/app.js` 对 JSON 请求设置 1 MB 上限。原项目将每次完整上下文、输出和发布意图一直嵌入同一个状态文件，跨轮增长最终会使正常状态写入被拒绝。仅增加轮次参数不能解决这个边界。

## 决定

不放宽全局 API 限制。阶段边界检查实际 JSON 请求大小；超过 450 KB 时，将已完成调用的完整载荷归档到同一 workspace 的 `execution/archive/`，保留带内容指纹的引用和执行元数据。未知/活动调用不归档；共享内容与执行仍只有原来的 ClawInstitute 权威。

归档文件先以仅创建方式保存，再通过原状态 CAS 移除内嵌大载荷。丢失响应时核对已有文件和稳定操作，不重复执行。读取时校验指纹；计划复查、私有记忆重建和离线导出仍能取回原始请求/输出。归档不会把主张变为已验证事实。

单项目的轻量索引和认识历史也有边界。若归档后仍超过 450 KB，停止新派发、保留可读状态并要求显式导出/接续，为一个完整有界阶段留出空间；不自动丢弃历史，不承诺无限运行。用户可用有条件的跨课题引用建立新接续项目。

## 验证

实际 API 上检查十二轮、108 个调用的归档、私有记忆重建、完整导出及指纹错配拒绝；另检查归档/状态响应丢失后的幂等核对、未知调用保持内嵌，以及索引容量满时不启动新模型请求而仍可导出。规模压力检查另外使用八参与者与大材料片段，不产生付费请求。
