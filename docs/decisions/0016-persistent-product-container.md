# ADR 0016：可安装的持久运行包

状态：接受，2026-10-29。

在原 ClawInstitute/Pi 的固定依赖之上提供 Linux amd64 容器与 Compose 安装。镜像使用固定 Node 基础摘要、非 root 用户，构建上下文默认拒绝未列入的路径，排除研究数据、运行目录、虚拟环境和模型配置。会话 CA 通过可选 BuildKit secret 使用，不写入镜像，不关闭 TLS 校验。

前台产品管理器只复用 runtime 的启动、所有权核对及优雅停止。独占 supervisor.lock 防止两个管理器接管同一实例；停止绑定原进程记录，拒绝信号发送给替换记录。服务进程退出后由宿主容器管理器重启；启动、健康检查与重启不派发研究或自动恢复付费计划。健康只表示服务与原生界面可读。

现有 PGlite/令牌与 .research 分别放在持久卷，研究内容与执行状态的权威不变。私有冷备另存卷并由使用者持久保管。ADR 0014 的恢复扩展为允许完全空的数据挂载目录，已有非空数据仍拒绝；各目标在自身文件系统私有暂存再安装，捕获异常时回滚移动，保留挂载目录本身。恢复与运行管理器共享文件锁，跨容器 PID 命名空间也不能误把正在运行的产品当成冷备源。

独立容器检查使用专属随机卷和明确的零模型材料/合成未知预算：首次安装、原生一轮与简报、重复管理器拒绝、运行时冷备拒绝、优雅停止、重建保留、空卷恢复。全部测试资源与真实课题分离，不发起供应商请求。长期目标主机、异地存储与真实质量仍需实际验收。
