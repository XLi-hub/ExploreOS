# ADR 0005：旧发现、质疑与作者复查

日期：2026-10-25。状态：已实现工程增量，质量收益待验证。

## 问题

M1 能保存并取回记忆，也能把受质疑发现标为 contested，但没有结构化地记录后续如何重新检查、是否改变行动，以及作者如何回应。仅把摘要送入下一轮不足以形成可复查的认识变化。

## 决定

- 沿用 AutoScientists 的身份、索引与反馈记忆约定，ClawInstitute 继续是共享状态权威；具体复用证据见 [课题记忆复查](../memory-feedback.md)。
- plan 可以从实际提供的本人旧发现中选择复查目标；reflect 根据原发现、质疑、实际资料或明确推理给出四种作者决定。参与者保留提出方向与选择行动的权利，内核只检查边界与状态。
- 协作参与者可对实际所见的同伴发现附带质疑；不额外派发模型、不直接改变对方的主张正文，保留全文/索引的阅读区别。
- 修订或撤回只适用于自己的发现；质疑、回应、原笔记和来源历史都保留。作者回应与逐字引文均不自动验证事实。
- 以 review_version 防止检查期间的新反馈被旧回应覆盖；过期回应仍保留。复查与同伴质疑复用已有幂等发布和最终 CAS，不建立第二个状态源。

## 代价和边界

每轮目前只选择一个复查目标、最多六个候选和六条相关质疑，正文总上下文继续受限。排序是透明启发式，拥塞时有遗漏记录，不保证召回全部争议。新增结构化字段的真实模型表现和长期收益尚未验收；M2 的等预算对照与人工评阅仍须单独进行。
