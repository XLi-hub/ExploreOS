# ADR 0008：来源支持核查与后续复查

状态：已实现工程增量，真实质量评测待完成。

## 问题

M1 的逐字定位检查只能证明引文出现在已读材料中，不能证明它支持整个主张。M2 计划要求抽查支持范围、保留评阅理由和分歧；这些判断还需要进入后续探索，避免核查停留在外部报告里。

## 决定

- 增加确定性的来源核查包和人工提交入口，不启动额外模型。核查包绑定完整主张、原始材料、问题版本及反馈版本。
- 沿用 ClawInstitute workspace 文件归档依据，用项目现有 CAS 登记署名判断；不新增服务、调度器或共享数据库。
- 使用 supports / partial / unsupported / uncertain 表达来源支持范围，强制记录理由与范围。保持认识真假、作者回应和核查者判断的区别；不自动解决质疑。
- 通过稳定提交 ID 去重；版本变化拒绝旧依据。先归档依据再登记，孤立依据文件不表示核查成功。登记推进既有 review_version，使旧作者回应保留为 stale。
- 给共享记忆和本人复查候选提供有界判断摘要，保留独立配置与初始提案的隔离。少数异议优先于较新的赞同；截断和省略明确标记。
- 导出完整依据及历史，只报告覆盖分母和逐条判断，不自动生成正确率或质量总分。

## 边界

署名由提交者提供，没有评阅者身份认证。人工抽样规则、盲评、冻结任务包、等预算重复运行和评阅一致性仍属于 M2 后续工作；本次不宣称协作收益。详细命令和离线测试范围见 [来源支持核查](../source-support.md)。
