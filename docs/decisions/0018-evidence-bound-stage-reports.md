# ADR 0018：带依据的阶段综合报告

状态：采用。日期：2026-11-01。

用户指出现有交付不足以称作产品。源码检查确认发现阶段仍受探针的百字提示与 900 token 上限约束，阶段简报主要罗列记录，不能充分回应实际问题。

保留原生共享空间与探索协议，新增显式报告操作，按完成轮次的已有发现组织阶段判断、竞争解释、限制和建议。报告复用原调用与预算设施，不另设调度器或存储。真实日常发现输出和报告分别使用受控的 3072 / 4096 token 预留，评测基线保持原有上限。

报告不是独立证据，不修改知识状态；引用只能来自实际上下文。输入指纹变化即标记历史。中断、取消、并发和发布响应丢失沿用现有认领/恢复路径。冻结评测禁止新增报告，新增执行代码纳入运行指纹。

供应商模型名和 Anthropic 接口与 [DeepSeek 官方文档](https://api-docs.deepseek.com/guides/anthropic_api/) 核对一致。托管执行器当前仍不可用，本次源码和机械检查不构成真实模型质量验收。实际使用见 [综合报告](../stage-reports.md)。
