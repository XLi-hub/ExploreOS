# ADR 0003：优先复用 AutoScientists 与 ClawInstitute

日期：2026-10-24。
状态：用户明确要求的复用方向；兼容性与真实运行尚待验收。
补充并调整：[ADR 0002](0002-multi-agent-exploration.md) 的实现路线。

## 背景

用户希望多用 AutoScientists 的现有实现，并明确提出 ClawInstitute。此前设计虽然采用多智能体探索机制，却把共享空间和运行底座重新选型放得过早，没有充分利用上游已有服务。

本次静态核对 AutoScientists 的 README、launch.py 和 runbook.md，以及 clawinstitute@0.1.3 的实际 npm 发布包。上游已经以 ClawInstitute 管理 workshop、智能体注册、共享文件与讨论；发布包还包含数据库和前端。核对范围与限制见[复用核对](../upstream-reuse.md)。

## 决定

1. 默认实施路线为 AutoScientists + ClawInstitute 的增量改造。先验证现有链路，再修改开放探索所必需的部分。
2. 优先沿用 workshop、workspace、posts、文件历史、智能体本地记忆和心跳/讨论/组队流程。已有前端先用于观察，不先另建完整工作台。
3. 优先通过 TASK.md、LAUNCH.md 和小型覆盖层适配开放问题。启动脚本和角色模板中的硬编码按证据局部修改，不能假设换任务文件就足够。
4. 编码代理执行器是可替换接口。先核对已有 Codex 适配，探索数据继续留在 ClawInstitute；不因换执行器重建协作服务。
5. 新增问题版本、认识状态、来源链接、预算和运行核对等缺口。每类状态明确唯一写入权威，不维护第二套帖子/团队/共享文件数据库。
6. 对已发现的并发写、平台和持久化限制做最小修补或边界约束，再用测试验证。优先在原服务或单一受控写入口解决，不直接换整个平台。
7. 只有出现具体且经验证无法合理适配的阻塞，才为受阻组件记录替换 ADR；通用代理框架不再与原生路线平行重做整套试验。

## 第一阶段交付

- 固定 AutoScientists commit 和 ClawInstitute 发布版本，记录发布包校验值、许可文件和平台前提。
- 在隔离数据目录上验证注册、讨论、共享读写、历史、冲突、重启和原有前端可用范围。
- 对开放任务列出 13 个 profile hook 的保留/修改/停用映射，并检查 profile 外的硬编码。
- 明确 Codex 执行接口与原服务之间的 ID、进程和状态对应关系。
- 交付一个有界、小规模开放探索任务；真实模型调用在实际配置与预算明确后进行。

这不是上游已经跑通的声明。本次只读分析发布材料并修订设计，没有安装服务、启动研究或复制上游实现代码进本仓库。
