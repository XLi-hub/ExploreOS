# ADR 0015：面向问题与成果的日常入口

状态：接受，2026-10-29。

用户明确要求最终可用的产品。原生探索视图已有操作能力，但创建要求技术代号，每次推进弹出后端及预算，默认页偏向记录浏览。

在原 ClawInstitute 扩展内增加阶段成果投影：沿用实际帖子、来源、问题版本和认识状态，不新增内容权威或模型调用。当前关注点的暂定/争议发现与历史版本、撤回/修订分开；过期复查不当作生效变化；已有作者回应不消除质疑。Markdown 下载来自同一投影，详细原始导出继续保留。

创建允许自动生成代号，高级参数折叠。执行选择保存在同一个版本化 Project 状态的 native_execution 字段，经原 CAS 提交；保留全部历史尝试，拒绝改变已运行课题的后端。首次实际执行仍由原执行器和预算控制，保存设置不会调用模型或新建预算池。真实与模拟结果不混合，冻结评测输入禁止通过此入口变更。

提供只读本机配置视图：凭据配置状态、固定 Pi 库是否存在、共享额度及未知请求数量。禁止返回密钥、供应商原始输出或完整预算明细。云环境启动策略只作为未验证连接的提示，不能当作实时网络健康检查；不通过配置查看偷偷探测或调用供应商。

这是产品使用流程的改进。真实质量验收和持久部署须实际完成，不能由此 ADR 代替。
