# ADR 0019：原生页面中的私有模型配置

状态：采用。日期：2026-11-02。

## 问题与决策

真实探索仍要求用户手工修改服务器 .env 并重建容器。沿用现有 ClawInstitute API、登录和私有访问边界，加入模型设置页面与受保护的配置接口，不增加独立服务或账号。

HTTP 写入必须匹配服务器实例登录令牌；不能依靠调用方自报身份或 owner 标记。配置使用服务器私有文件、原子替换和文件锁，带独立版本防止过期页面覆盖新值。公开接口仅返回状态、配置来源和非秘密版本；不返回密钥。

环境变量优先且在页面只读，兼容原私有文件。页面配置位于既有 service 命名卷中，正常容器替换保留，冷备归档排除。配置操作不派发模型、不创建预算、不改变未知请求额度。

## 验证与边界

覆盖状态不落盘、私有权限、并发/过期写拒绝、环境配置保护、原配置兼容、值不回显、HTTP 认证、浏览器保存/重开/移除、容器替换和备份排除。测试使用明确的无效供应商样例，不发起付费请求。

该入口遵循个人或单一可信使用者范围。持有实例登录令牌者具有管理能力，不能据此宣称多租户隔离。源码、机械和浏览器检查不代替真实模型质量与长期部署验收。使用说明见 [模型设置](../provider-setup.md)。
