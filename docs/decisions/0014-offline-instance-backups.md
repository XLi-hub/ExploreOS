# ADR 0014：现有 ClawInstitute 实例的离线备份

状态：已实现，实际恢复检查另见验证记录。

## 依据与决定

M5 的持久运行仍缺一条可执行、可核对的数据迁移和恢复路径。单个课题导出用于审阅；恢复实例还需要同一数据库中的文件历史、身份、讨论、预算及本地课题/评测引用，不能只复制可见报告后重建一个空账本。

使用现有 PGlite 数据目录的冷备份，将其与 `.research/` 及本地服务 token 放在一个权限 600 的归档中。源码、固定依赖及独立模型密钥配置分开管理，不加入服务日志或旧进程记录。停止控制器/服务后，沿用原 manager lock，检测源文件变化，再发布归档。

恢复先完整流式检查清单、路径、类型与内容摘要，再向空数据目录安装；失败回滚，不覆盖现有课题。归档是恢复材料，运行后仍由 ClawInstitute 与原执行账本拥有状态；没有建立第二个数据库权威或重置调用预算。

隔离验证直接复用上游 PGlite、WorkspaceFileService 与原数据表，检查材料版本、完整历史、身份、帖子/回复和未结算额度。它不启动模型。CI 也执行该验证，不上传归档。

## 边界

仅验证当前固定版本的本地 PGlite 冷备，不宣称在线备份、跨版本升级、异地自动备份或任意断电点零丢失。恢复实例接替已停用的原实例，不同时运行两个有独立账本的副本。归档内容校验不提供来源签名；私有归档需由操作者妥善保存。使用见 [备份与恢复](../backup-restore.md)。
