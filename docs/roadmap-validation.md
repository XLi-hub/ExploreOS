## 固定任务机械运行

任务包为 `examples/evaluation/pilot.json`，版本 pilot-1。五个开放问题、三个有明确核查点的问题，每个任务均有原问题、第二轮关注点和材料快照。

本次完整机械 campaign 使用七种配置、一次重复、两轮，共 **56/56 个案例完成，816 次模拟阶段调用，付费供应商请求为 0**。协议指纹为 `6c8f911fbae1c99138c020674646bcff289ee4e374952c674b0160ce860b05bd`。原始状态和导出保存在私有 `.research/evaluations/pilot_all_controls/`；不上传数据库和完整运行目录。

这只证明固定输入、不同配置、接续、来源快照与确定性报告可以运行。没有因此判断八个问题的答案正确、协作有收益或真实领域中记忆有效。默认真实评测设计为三次重复；本次一次机械重复不能替代它。

测试包含来源核查、完整 SDK/前台委派、工作记忆与作者复查、认领/预算/超时/取消、评测冻结与接续、人数参数、跨课题记忆、定时重复唤醒/停用/未知供应商以及真正 SIGKILL 后恢复。SDK 测试使用实际库和服务，供应商为替身，未发生真实模型费用。

在长期边界检查中确认上游 JSON 写入上限为 1 MB，随后补充了带指纹的调用归档与派发前容量检查。十二轮/108 个调用的实际 API 运行、记忆重建和完整导出通过；归档丢失响应和未知调用保留也通过。原始历史没有因紧凑索引而被删除。

浏览器验证使用系统 Chromium + Playwright：桌面与手机布局、无横向溢出、来源行号、方向与历史标签、先读依据再提交判断，以及实际创建→推进→暂停→改向→继续→导出→重新打开的完整操作。导出保留了两个问题版本，机械性质没有变成真实质量证据。

## 原生 ClawInstitute 集成

根据用户要求，取消独立 3388 工作台服务，将探索视图挂入既有 Express API，并通过既有 Next 重写从 3001 同源访问。认证沿用原登录；TASK 首帖和共享文件提供入口，探索页面返回原讨论/文件。补丁和指纹受版本控制，见 [ADR 0012](decisions/0012-native-clawinstitute-extension.md)。

已通过实际 API 认证/Origin/Host 检查及 Chromium 完整操作链。模型凭据仅由服务端读取，网页与导出不含其内容。

冻结评测还增加输入保护：受绑定案例不能手工改问题、材料、人数/策略、额度或添加跨课题输入，也不能绕过 campaign 手动执行。运行前与执行认领时均核查冻结输入；旧报告仍可只读导出。

## 原生操作补齐

继续核对发现原页面缺少 CLI 已有的材料增补、有限追加轮次、执行恢复与跨课题引用操作。本次将它们接入原 ClawInstitute 扩展，保留同一快照、预算、恢复与引用约束。新增校验覆盖材料超限拒绝、重试绑定实际调用、未知额度保留、冻结输入及来源异议变化，设计见 [ADR 0013](decisions/0013-native-exploration-controls.md)。没有为此新增另一套调度或数据库。完整验证以本次最新提交的测试/CI 为准。
